# Alien Invasion

A space shooter built with **Pygame**, based on Chapter 12 of
*Python Crash Course* by Eric Matthes.

I modified it a bit.

## Summary

Alien Invasion is a 2D side-scrolling space shooter. The player controls
a ship that moves horizontally along the bottom of the screen and fires
bullets upward. The goal is to survive waves of descending aliens while
destroying as many as possible. The game features a simple score system,
lives, and increasing difficulty as the alien fleet descends. You'll learn OOP here a lot!

## How to Run

1. Install Pygame:
   pip install pygame
   
   #Depends on the pygame version, you can do "py" or "python". Then the name of the file which also depends on you
3. Run the game:
   python alien_invasion.py or py alien_invasion.py

## Project Structure

├── settings.py         # Game configuration
├── ship.py             # Ship class
├── bullet.py           # Bullet class
└── images/             # Sprite assets
